# Security

## Reporting a vulnerability

If you believe you have found a security issue in this repository or the published app, please report it **privately** so it can be addressed before public disclosure.

**Preferred:** use [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for this repository (“**Security**” tab → “**Report a vulnerability**”), if the maintainer has private reporting enabled.

Include a short description, steps to reproduce, and impact if you can. Do not open a public issue for undisclosed vulnerabilities.

## Scope note

QR decoding and generation in this project are intended to run **client-side** in the user’s browser. When assessing risk, focus on supply chain, dependency, and hosting misconfiguration issues rather than “data sent to our API” for core QR flows.
